# Fonts

Four self-hosted subsets, generated by `scripts/fonts.mjs` from pinned releases.
`public/fonts/ui-charset.json` records the covered characters and file sizes;
`public/fonts/LICENSE-*` carry the upstream license texts.

| File                | Subset family | Upstream                                        | Role                                                   | License                                           | Size   |
| ------------------- | ------------- | ----------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------- | ------ |
| `uiviu-kai.woff2`   | UIVIU Kai     | LXGW WenKai v1.520 Regular                      | hero slogan, page/article titles, `h2`                 | SIL OFL 1.1 + Additional Permission (web subsets) | 63 KB  |
| `uiviu-hei.woff2`   | UIVIU Hei     | LXGW Neo XiHei v1.308 Regular                   | body prose, `h3`, navigation, UI                       | **IPA Font License 1.0**                          | 44 KB  |
| `uiviu-meta.woff2`  | UIVIU Meta    | Maple Mono v7.9, `wght` pinned to 400           | dates, category labels, reading time, pagination, code | SIL OFL 1.1                                       | 28 KB  |
| `uiviu-pixel.woff2` | UIVIU Pixel   | Fusion Pixel 10px monospaced zh_hans 2026.10.25 | the `404` digits only                                  | SIL OFL 1.1                                       | 0.8 KB |

## Why the subsets are renamed

Subsetting is a modification. Both SIL OFL (Reserved Font Names) and the IPA
license (Article 3.1(4): a derived program may not use the original program's
name) forbid redistributing the modified font under the original name. The build
therefore rewrites the internal `name` table to `UIVIU Kai / Hei / Meta / Pixel`
and uses neutral file names; the copyright and license name records from the
originals are preserved unchanged.

The IPA license additionally requires that recipients can replace the derived
program with the original, and that the derived program is distributed under the
same agreement. This directory satisfies both: the license text is shipped next
to the font, and the pinned upstream URL plus `scripts/fonts.mjs` reproduce the
identical subset from the original (or let you replace it with the original).

WenKai's OFL carries an Additional Permission allowing web-only subsets to keep
its reserved names; the subsets are still renamed for consistency.

## Rebuilding

```bash
pnpm fonts:ensure   # check, rebuild only when new copy needs glyphs
pnpm fonts:build    # force a rebuild
pnpm fonts:check    # strict audit: fail instead of rebuilding
```

`pnpm dev`, `pnpm build` and `pnpm verify` all start with `fonts:ensure`, so
writing a post and pushing is enough; every font, including the pixel face,
derives its characters from the same automatic scan. Sources are downloaded once
with Node's `fetch` into `.fonts-cache/` (git ignored; cached in CI) and never
committed — full fonts are 24 MB / 7 MB / 128 KB / 3 MB upstream. No `curl`,
`unzip` or Python is needed on the build image.
